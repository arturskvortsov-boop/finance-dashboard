# 📁 Финансовый дашборд — карта проекта

## Что это
Личное PWA-приложение для учёта финансов + Telegram-бот с напоминаниями.
Размещено на GitHub Pages, данные хранятся в JSON-файлах в самом репозитории.
Синхронизация между устройствами — через GitHub API.

## 🏗 Архитектура

### Файлы в репозитории
- `index.html` — разметка PWA
- `style.css` — стили (тёмная тема, CSS-переменные)
- `app.js` — вся логика PWA (~1700 строк)

- `stats2.json` — транзакции
- `rate.json` — история курса USD

- `goals.json` — цели накоплений
- `reminders.json` — кастомные напоминания
- `README.md` — описание

### Формат данных

**stats2.json:**
```json
{"text":"🟢 ДОХОД | 25.09.2026, 12:11 | 8900 Долларов 🇺🇸 -> 764243 Рублей 🇷🇺 | 💰 Зарплата | За август\n🔴 РАСХОД | ..."}
```

**rate.json:**
```json
{"text":"25.08.2026, 13:56 | 83,44\n26.08.2026, 14:30 | 84,10\n..."}
```

**templates.json / budgets.json / goals.json / reminders.json:** массив объектов JSON.

**Формат reminders.json:**
```json
[{
  "id": "rem_1234567890_123",
  "text": "Позвонить маме",
  "dueAt": "2026-09-27T15:00:00.000Z",  // UTC
  "status": "pending",
  "createdAt": "2026-09-27T05:55:32.640Z"
}]
```

### Стек
· Vanilla JS (ES5, без сборщиков) · Chart.js 4.4 (графики) · open.er-api.com (живой курс USD) · cbr-xml-daily.ru (курс ЦБ РФ) · Telegram WebApp SDK · Python 3.12 + requests (серверный бот) · systemd (сервис бота)

## 🎯 Что реализовано

### PWA
· Учёт транзакций: вручную, через Siri Shortcuts, через шаблоны
· Синхронизация с GitHub через Personal Access Token (хранится в localStorage)
· Автосинхронизация: после действия (2 сек), при входе, при выходе/возврате
· Merge-логика — не теряет данные при конфликтах
· Retry при 409 (до 4 попыток с задержкой)
· Курс: живой с open.er-api.com + официальный ЦБ РФ
· USD-эквивалент баланса, курсовая разница
· Диаграммы: доход/расход по категориям (doughnut)
· Кумулятивный график «доход vs расход» (2 линии, растут от начала)
· Сегментный график курса USD/RUB (зелёные участки роста, красные падения)
· Прогноз на конец месяца (по среднему темпу)
· Календарь трат (с листанием по месяцам, цветовая шкала)
· Сравнение с прошлым месяцем (стрелки ▲▼)
· Шаблоны (регулярные платежи)
· Бюджеты по категориям с прогресс-барами
· Цели накоплений
· Напоминания по шаблонам (дата месяца)
· Кастомные напоминания (с датой/временем, отправляются через бота)
· Поиск и фильтр в истории
· Скрытие баланса (👁)
· Экспорт JSON / CSV, импорт JSON
· Только тёмная тема (светлая убрана)
· Нижняя навигация: 🏠 + капсула (💵 ⚙️ ⋯) + FAB
· FAB-веер: 🔁 Повторить, ➕ Добавить, ⚡ Быстрое, ☁️ Синхронизация, 🔄 Обновить
· Bottom sheet «Ещё» со всеми действиями
· Pull-to-refresh
· Свайпы между вкладками
· Анимации появления транзакций, чисел, страниц
· Округление сумм (рубли — целые, USD — 2 знака)
· Нормализация категорий (склеивание дубликатов из-за скобок, U+FE0F)
· Фильтр «Месяц» — календарный (с 1-го числа), а не «последние 30 дней»

### Telegram Mini App
· SDK подключён
· Авторизация через реальный Telegram ID (tg_...)
· Back Button (закрывает модалки/шторки/веер)
· Fullscreen только на мобильных (tg.platform === 'ios'|'android'), не на десктопе
· Тёмные цвета хедера и bottom bar
· Приветствие «👋 Привет, Артур!» при первом открытии
· Отступы под кнопки Telegram

### Telegram Bot (@Mufasa_statsbot)
· systemd-сервис на сервере (Ubuntu 24.04, /root/finance-bot/bot.py)

· Команды: /start, /help, /balance, /stats, /reminders

## 📂 Структура серверной части

```
/root/finance-bot/
├── bot.py           (~403 строки, Python 3.12)
├── .env             (токен бота, chat_id, github-данные)
├── sent_ids.json    (ID отправленных напоминаний)
├── offset.json      (offset для Telegram polling)
├── log.txt          (лог работы)
└── cron.log         (старый лог cron, больше не используется)
```

### Сервис systemd

Файл: `/etc/systemd/system/finance-bot.service`

```
[Unit]
Description=Finance Telegram Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/finance-bot
ExecStart=/usr/bin/python3 /root/finance-bot/bot.py --daemon
Restart=always
RestartSec=10
StandardOutput=null
StandardError=null

[Install]
WantedBy=multi-user.target
```

**Управление:**
· systemctl status finance-bot — статус
· systemctl restart finance-bot — перезапуск
· tail -20 /root/finance-bot/log.txt — логи
· ps aux | grep bot.py — процессы

## 🔑 Ключевые технические моменты

### Категории (важно!)

Доходы: 💰 Зарплата, 🗓 Продажа, 🎁 Подарок, 💵 Другое

Расходы: 🚘 Автомобиль, 🍔 Еда, 🏚️ Ипотека, ☕️ Кафе, 🎢 Развлечения, 🛍 Покупки, 💊 Здоровье, 🏠 Коммуналка, 📱 Связь, 📚 Образование, 💸 Другое

### Нормализация категорий

Функция `normalizeCategory()` убирает U+FE0E / U+FE0F (variation selectors) и обрезает всё в скобках. Это склеивает дубликаты вроде `🛍 Покупки (Одежда)` и `🛍 Покупки`.

### Merge транзакций

`mergeTransactions(local, remote)` — объединяет по ключу тип|дата|руб|usd|категория|коммент. Не теряет данные.

### Курс USD

При расчёте баланса: если `tx.usd > 0`, сумма = `usd * currentUsdRate`. Иначе — `tx.rub`. Это важно для бота — он использует ту же логику.

## ⏳ Что в процессе / на очереди

### Незаконченное (срочно)
1. Кастомные напоминания: последний патч (3 части) — анимация и баланс USD на вкладке «Валюта» переключены на накопительный баланс. Часть патча не применена.

### Запланированные фичи (обсуждали)
1. `/add` и `/remind` в боте — добавить транзакции и напоминания прямо из чата. Нужен GitHub-токен в .env бота.
   · `/add 500 еда` → расход 500 ₽ в «🍔 Еда»
   · `/add +5000 зарплата` → доход
   · `/remind Позвонить маме 28.09 18:00` → напоминание
2. Общий дневник с женой (Семейный бюджет) — план:
   · Итерация A: поле author в транзакции + переключатель «Кто вносит» + метка в истории
   · Итерация B: фильтр «Мои / Её / Все» в истории
   · Итерация C: два chat_id в боте (напоминания обоим)
   · Итерация D: личные цели (общие/личные)
3. Голосовой ввод через Siri Shortcuts — «Siri, добавь расход 500 еда»

### Возможные улучшения (обсуждали, не делали)
· Онбординг
· Экспорт PDF
· Расширение категорий (вместо тегов)
· Умные предупреждения (>20% бюджета за одну трату)
· Конвертер валют
· Импорт CSV банковских выписок
· Push через Telegram о превышении бюджета

### Известные ограничения
· iPhone: не получилось подключиться к серверу через Termius (SSH через телефон не настроен, работаем через PuTTY на ноуте)
· Cron больше не используется (заменён на systemd-сервис)
· GitHub Actions не используем — есть свой сервер
